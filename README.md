# GSVS UK ACM projects have a new home

GSVS projects previously hosted under `xboxnuker-rgb` have moved to the
[GSVS-UK-ACM organisation](https://github.com/GSVS-UK-ACM).

Existing repository links redirect to their new home. Use the organisation's
repositories for current source, releases, issues and pull requests.

The private [Projects Hub](https://github.com/GSVS-UK-ACM/GSVS-Projects-Hub) has
also moved. Existing Android users should install the signed viewer 1.1.3 update
from the Hub. Repository access is still required.
