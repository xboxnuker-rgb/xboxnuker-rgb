# GSVS UK ACM projects have a new home

GSVS projects previously hosted under `xboxnuker-rgb` are moving to the
[GSVS-UK-ACM organisation](https://github.com/GSVS-UK-ACM).

Existing repository links redirect to their new home. Use the organisation's
repositories for current source, releases, issues and pull requests.

The Projects Hub is being moved last so its existing Android viewer can be
updated safely. Its current link continues to work during that final step.
